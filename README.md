# website

A personal collection of links and resources.

## Adding links

Open `links.js` and add a line to a group's `links` list:

```js
"https://example.com",
```

To show a name instead of the address, write `{ url: "https://example.com", label: "Example" },`.

## Previewing on your computer

From this folder, run:

```bash
python3 serve.py
```

Then open http://localhost:4321.
